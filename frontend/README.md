# Витрина интернет-магазина (React + Vite)

Клиентская часть демо-магазина (лампочки): **React 19**, **Vite**, **React Router DOM**. Backend не подключается — каталог и логика заказа на **mock-данных**; корзина дополнительно **сохраняется в `localStorage`**, чтобы позиции не пропадали после перезагрузки страницы.

## Что готово

- **Каталог** (`/catalog`): сетка товаров, слайдер, боковая панель фильтров (цена, категория, цоколь, мощность, бренд, форма), поиск и категория в шапке; на мобилке поиск в полноэкранном бургер-меню.
- **Карточка товара** (`/product/:id`): фото-заглушка, описание, цена, количество, в корзину / в корзину перейти; компактная шапка на странице товара.
- **Корзина** (`/cart`): упрощённая шапка (лого + «Вернуться к покупкам»), список позиций, итог, оформление.
- **Оформление** (`/checkout`): лого, возврат в корзину, **случайный числовой номер заказа** (показывается до отправки), состав заказа, данные получателя, **проверка телефона РФ**, кнопка отправки.
- **Подтверждение** (`/confirmation`): номер заказа из перехода с checkout.
- **Авторизация и регистрация** (`/login`, `/register`): формы без backend (имитация успешного сценария).
- **Общая вёрстка**: белый фон, полноширинный макет, с **900px** — боковые поля по **100px**; адаптив **от 320px**; общий утилитарный класс `.visually-hidden` в `index.css`; хук **`useMatchMedia`** для брейкпоинтов (шапка).

Админ-панель в проекте **не реализована** (по ТЗ не требуется).

## Запуск

```bash
npm install
npm run dev
```

В браузере откройте адрес из вывода Vite (обычно `http://localhost:5173`).

## Скрипты

| Команда | Назначение |
|--------|------------|
| `npm run dev` | режим разработки с HMR |
| `npm run build` | production-сборка в `dist/` |
| `npm run preview` | просмотр собранного приложения |
| `npm run lint` | ESLint |

## Маршруты

| Путь | Страница |
|------|----------|
| `/` | редирект на `/catalog` |
| `/catalog` | каталог |
| `/catalog?search=…` | каталог с поисковым запросом из строки |
| `/product/:id` | товар |
| `/cart` | корзина |
| `/checkout` | оформление заказа |
| `/confirmation` | подтверждение (нужен переход после оформления) |
| `/login`, `/register` | вход и регистрация |
| `*` | редирект на `/catalog` |

## Структура (основное)

- `src/pages/` — страницы приложения
- `src/components/` — шапка, подвал, слайдер, фильтры, карточка товара
- `src/context/` — `CartProvider`, корзина + сохранение в `localStorage`
- `src/hooks/` — `useProductCartQty`, `useMatchMedia`
- `src/data/mockProducts.js` — мок-каталог и хелперы

## Проверка перед сдачей

```bash
npm run lint
npm run build
```

Дополнительно вручную: сценарий каталог → товар → корзина → checkout → confirmation, узкая ширина **320px** в DevTools, перезагрузка страницы с непустой корзиной.
