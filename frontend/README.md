# Витрина интернет-магазина (React + Vite)

Клиентская часть магазина: React 19, маршрутизация **React Router DOM**, без backend — товары и заказы на **статических mock-данных**.

## Запуск

```bash
npm install
npm run dev
```

Откройте в браузере адрес, который покажет Vite (обычно `http://localhost:5173`).

## Скрипты

| Команда | Назначение |
|--------|------------|
| `npm run dev` | режим разработки с HMR |
| `npm run build` | production-сборка в `dist/` |
| `npm run preview` | локальный просмотр собранного приложения |
| `npm run lint` | проверка ESLint |

## Маршруты

- `/catalog` — каталог (фильтр по цене, категории и поиск в шапке)
- `/product/:id` — карточка товара, добавление в корзину
- `/cart` — корзина
- `/checkout` — оформление заказа (форма)
- `/confirmation` — подтверждение с номером заказа

Корень `/` перенаправляет на `/catalog`.

## Структура (основное)

- `src/pages/` — страницы
- `src/components/` — шапка, слайдер, фильтр, карточка товара, подвал
- `src/context/` — контекст корзины (`CartProvider`, `useCart`)
- `src/data/mockProducts.js` — мок-каталог

## Адаптивность

Вёрстка рассчитана на ширину от **320px**; сетка каталога и шапка перестраиваются на контрольных ширинах (например, 480px, 640px, 900px).
